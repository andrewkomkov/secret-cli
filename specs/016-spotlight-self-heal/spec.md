# Feature Specification: SecretBar сам восстанавливает индекс Spotlight

**Feature Branch**: `016-spotlight-self-heal`. Работа идёт в `main` локальной репы.

**Created**: 2026-10-08

**Status**: Done 2026-10-08

**Input**: Агент проверил приложение 2026-10-08 после установки сборки 12:13. `tests/run.sh`
упал на проверке «015: spotlight index of the installed app». `--spotlight-check` показал 0
записей при 65 секретах. После перезапуска SecretBar в индексе снова 65 записей.

Система стёрла индекс приложения после того, как приложение построило его при запуске. Приложение
строит индекс заново только при изменении списка секретов. Поэтому пустой индекс остаётся
пустым до перезапуска или до нового секрета.

## User Scenarios & Testing *(mandatory)*

### User Story 1 - Spotlight находит секреты без перезапуска (Priority: P1)

1. **Given** Spotlight включён в настройках и индекс приложения пуст или неполон, **When**
   проходит 10 минут, **Then** приложение строит индекс заново. Spotlight снова находит все
   секреты.
2. **Given** индекс полный, **Then** приложение не меняет индекс.
3. **Given** Spotlight выключен в настройках, **Then** приложение не строит индекс.

### Edge Cases

- Запрос к индексу вернул ошибку. Приложение не меняет индекс и проверяет его снова через 10
  минут.
- Список секретов пуст. Приложение не проверяет индекс.

## Requirements *(mandatory)*

- **FR-001**: при запуске и каждые 10 минут приложение сравнивает число записей своего
  индекса Spotlight с числом секретов. При расхождении приложение строит индекс заново.
- **FR-002**: в индекс идут только имена и комментарии. Значений в индексе нет.
- **FR-003**: `--spotlight-check` и приложение считают записи одной функцией.

## Success Criteria *(mandatory)*

- **SC-001**: агент очищает индекс приложения флагом `--spotlight-clear`. Через 10 минут
  индекс снова полный, а приложение работает без перезапуска.
- **SC-002**: `tests/run.sh` проходит на установленном приложении.

## Assumptions

- Индекс очищает система, например при переустановке или перестройке Spotlight. Приложение
  не знает причину. Поэтому оно проверяет результат.
