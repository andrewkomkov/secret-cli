# Implementation Plan: Маскировка для агента по умолчанию

**Branch**: `006-agent-auto-mask` | **Date**: 2026-10-02 | **Spec**: [spec.md](spec.md)

## Summary <!-- slop: заголовок задан шаблоном spec-kit -->

В `cmd_run` флаг `mask` ставится в 1 при непустом `CLAUDECODE`, `--no-mask` его снимает только
без `CLAUDECODE`. В `MASK_PL` к каждому значению длиной от 8 символов добавляются варианты:
`MIME::Base64::encode_base64` (с `=` и без), URL-safe base64 и URL-кодирование `%XX`. Модули —
из ядра perl.
