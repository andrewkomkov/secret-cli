# Implementation Plan: Защита от утечек при работе агента

**Branch**: `001-agent-safety` | **Date**: 2026-10-02 | **Spec**: [spec.md](spec.md)

## Summary <!-- slop: заголовок задан шаблоном spec-kit -->

Четыре добавления в `bin/secret` и один новый файл хука.

- `gen`: куски по 512 байт из `/dev/urandom` через `tr -dc` до нужной длины, запись через
  `cmd_set` (значение идёт в stdin `security -i`).
- `run --mask`: команда запускается без `exec`. stdout идёт в маскировщик через pipe, stderr —
  через FIFO во второй маскировщик. Маскировщик — `perl`, значения он получает в переменной
  окружения только своего процесса и заменяет их от длинных к коротким. Код выхода берётся из
  `PIPESTATUS[0]`, потом скрипт ждёт маскировщик stderr.
- Журнал: функция `audit` пишет строку TSV, `secret log` — `tail` и фильтр по имени.
- Хук: `perl` с `JSON::PP` (есть в системном perl) достаёт `tool_input.command`, проверяет
  шаблоны, при совпадении — код 2 и причина в stderr.

## Technical Context

**Language and version**: bash 3.2, perl 5 (системный)

**Testing**: `tests/run.sh`; для хука — JSON на stdin и код выхода

**Constraints**: конституция, принципы I, III, IV

## Constitution Check

| Принцип | Как соблюдается |
|---|---|
| I | `gen` и `log` не выводят значений; маскировщик получает значения не через `argv` |
| II | `gen` не заменяет ввод человеком: он создаёт новое значение, которого не знает никто |
| III | только `bash`, `perl`, `tr`, `mkfifo` |
| IV | все проверки в `tests/run.sh`; журнал в тестах пишется во временный файл |
| V | `run` без `--mask` работает как раньше (`exec`) |
