# Feature Specification: хранилище Secure Enclave без срока подписи

**Feature Branch**: `017-secure-enclave-store`. Работа идёт в `main` локальной репы.

**Created**: 2026-10-14

**Status**: Done 2026-10-14

**Input**: Владельцу нравится, как работает хранилище data protection. Но его helper живёт на
profile бесплатной Personal Team, а profile кончается через 7 дней. Продление идёт само раз в
сутки, но требует входа в Xcode и сети. Владелец хочет тот же опыт без продления.

Прототип 2026-10-14 (агент, касания — владелец):

- Программа с подписью ad-hoc создала ключ P-256 в Secure Enclave. Team и entitlements ей
  не понадобились.
- Ключ работает только после подтверждения. Иначе система отвечает «User interaction is
  required».
- С `.userPresence` подтверждение приходит и на Apple Watch.
- Обёртка ключа работает и в другой программе. Поэтому обёртку хранит запись файлового keychain.
  Без вопроса эту запись читает только helper.

## User Scenarios & Testing *(mandatory)*

### User Story 1 - Тот же опыт без срока (Priority: P1)

1. **Given** хранилище Secure Enclave включено, **When** агент или владелец читает секрет,
   **Then** macOS спрашивает Touch ID или Apple Watch один раз. Потом действует grace.
   Grace — 30 минут простоя, предел 8 часов. Блокировка экрана, сон и `secret lock` заканчивают grace.
2. `ls`, `has`, `check`, `note`, `expire`, `set`, `gen`, `ask`, `import` работают без Touch ID.
3. SecretBar, быстрая панель, Spotlight и журнал работают как раньше.
4. Команда и SecretBar молчат про profile и продление.

### User Story 2 - Переезд одной командой (Priority: P1)

1. **When** владелец запускает `secret migrate --vault`, **Then** команда читает все значения
   из хранилища data protection (одно касание). Она пишет их в новое хранилище. Потом она читает
   их из нового хранилища (одно касание) и сравнивает. Только после этого команда переключает
   режим на новое хранилище.
2. Команда оставляет записи хранилища data protection. `secret migrate --dp` возвращает команду
   туда и переносит изменения обратно.
3. `secret migrate --back` из нового хранилища переносит секреты в файловый keychain.

### User Story 3 - Чужая программа не читает секреты (Priority: P1)

1. Файл хранилища без ключа файла — шум: имён и комментариев в нём не видно.
2. Ключ файла и обёртку ключа Secure Enclave без вопроса читает только helper. Другая программа
   получает системный запрос пароля keychain.
3. Подменённый или повреждённый файл helper отвергает и не пишет поверх него.

### Edge Cases

- Файл хранилища есть, записи keychain нет. Helper завершается с ошибкой и сохраняет прежний
  ключ. `secret touchid repair` восстанавливает запись.
- Две записи в одно время: вторая ждёт первую (блокировка файла).
- Сбой при записи: прежний файл остаётся целым (запись во временный файл и rename).
- Ключ Secure Enclave пропал (Mac стёрт): значения не читаются. Восстановление — из резервной
  копии `secret export`.

## Requirements *(mandatory)*

- **FR-001**: новый helper понимает те же запросы, что helper data protection: `list`, `has`,
  `read`, `write`, `attrs`, `delete`, `policy`, `lock`, `status`, `grace-status`, `clip`,
  `ping`, `kind`.
- **FR-002**: значение в файле зашифровано открытым ключом Secure Enclave, весь файл — ключом
  файла. Значение не попадает на диск открытым текстом.
- **FR-003**: подтверждение — `.userPresence`: Touch ID, Apple Watch или пароль Mac.
- **FR-004**: grace, предел 8 часов, блокировка, сон и `lock` работают как в data protection.
- **FR-005**: `secret migrate --vault`, `--dp`, `--back` с проверкой каждого значения.
- **FR-006**: helper собирает `install.sh` через `swiftc`, без Xcode и profile.
- **FR-007**: `touchid status` в новом хранилище пишет `store: secure enclave` и не пишет
  profile. SecretBar не показывает предупреждение о profile.
- **FR-008**: тесты проходят на тестовой сборке с программным ключом.

## Success Criteria *(mandatory)*

- **SC-001**: после переезда все 65 секретов читаются, значения совпадают.
- **SC-002**: одна команда `secret run` с несколькими именами спрашивает подтверждение один раз,
  вторая в grace — ни разу.
- **SC-003**: helper работает после 19 октября 2026 года, когда кончается последний profile, без
  `install.sh --renew`.
- **SC-004**: `tests/run.sh` проходит целиком.

## Assumptions

- Ключ Secure Enclave привязан к этому Mac, как записи `ThisDeviceOnly` сейчас.
- Имена и комментарии внутри helper и в выводе `ls` — не тайна для владельца и агента, как
  сейчас.
