# Implementation Plan: Служебные записи без Touch ID

**Branch**: `011-meta-items` | **Date**: 2026-10-07 | **Spec**: [spec.md](spec.md)

## Summary <!-- slop: заголовок задан шаблоном spec-kit -->

Имя, комментарий и срок секрета переходят в служебную запись без `.userPresence`. Запись со
значением читает только агент. `bin/secret` проверяет helper командой `ping`. Тестовая сборка
пишет каждое обращение к записи со значением в журнал, тесты его проверяют.

## Constitution Check

| Принцип | Как соблюдается |
|---|---|
| I | значения без изменений |
| II | одно окно Touch ID на grace, атрибуты без Touch ID |
| IV | журнал обращений в тестовой сборке заменяет окна, которых в тестах нет |
| V | `secret __reindex` один раз переводит хранилище 009 |
