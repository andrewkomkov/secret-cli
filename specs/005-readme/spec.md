# Feature Specification: README

**Feature Branch**: `005-readme` (работа идёт в `main` локальной репы)

**Created**: 2026-10-02

**Status**: Done — 2026-10-02

**Input**: Владелец хочет современный README: с первого экрана понятно, что это, зачем и как
начать.

## User Scenarios & Testing *(mandatory)*

### User Story 1 - Понять за минуту (Priority: P1)

Человек открывает README и на первом экране видит: что делает команда, чем она отличается,
как её поставить и первый пример.

**Acceptance Scenarios**:

1. **Then** вверху название, одна строка о назначении, значки (macOS, bash, тесты), навигация.
2. **Then** быстрый старт — не больше 6 команд.
3. **Then** схема: как агент получает секрет и не видит значение.
4. **Then** команды разбиты на группы, полный справочник свёрнут.
5. **Then** модель угроз: что защищено и что нет, таблицей.

## Requirements *(mandatory)*

- **FR-001**: Всё, что было в README, остаётся: команды, переменные, ограничения, бэкап, Touch ID, хук, тесты.
- **FR-002**: Устаревшие строки исправлены: Touch ID есть, заблокированный keychain тесты проверяют через helper.
- **FR-003**: Без эмодзи. Схема — Mermaid (рисуется в GitHub и в редакторах Markdown).

## Success Criteria *(mandatory)*

- **SC-001**: Все команды из `secret help` есть в README.
- **SC-002**: Число тестов в значке совпадает с выводом `tests/run.sh`.
