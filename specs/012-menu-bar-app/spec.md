# Feature Specification: Приложение в строке меню SecretBar

**Feature Branch**: `012-menu-bar-app`. Работа идёт в `main` локальной репы.

**Created**: 2026-10-07

**Status**: In progress

**Input**: Владелец попросил приложение с интерфейсом: «всё, чтоб прям премиальная аппка была»,
и журнал обращений, последние 20.

## User Scenarios & Testing *(mandatory)*

<!-- утр-100: 8.2 — заголовки заданы шаблоном spec-kit -->
### User Story 1 - Состояние и блокировка (Priority: P1)

1. **Given** grace активен, **Then** значок в строке меню — открытый замок. Окно показывает,
   сколько осталось.
2. **When** «Заблокировать», **Then** grace заканчивается, значок — закрытый замок.
3. **Given** срок profile helper меньше 2 дней или есть истёкший секрет, **Then** значок
   предупреждает.

### User Story 2 - Секреты (Priority: P1)

1. **When** окно открыто, **Then** список имён, комментариев и сроков без Touch ID, поиск по имени
   и комментарию.
2. **When** «Копировать», **Then** значение в буфере обмена, очистка через 30 секунд. Touch ID
   нужен, если grace закрыт.
3. **When** «Добавить», **Then** имя, комментарий, срок, значение в скрытом поле или генерация.
4. **When** «Изменить», «Переименовать», «Удалить», **Then** приложение выполняет команды
   `secret note`, `expire`, `set`, `mv`, `rm`. Удаление приложение подтверждает отдельно.

### User Story 3 - Активность (Priority: P2)

1. **Then** последние 20 строк журнала доступа: время, агент или человек, операция, имена.

### User Story 4 - Настройки (Priority: P2)

1. Время grace (0, 5, 15, 30, 60 минут), с Touch ID.
2. Срок profile helper и кнопка «Продлить».
3. Резервная копия в файл с паролем.
4. Запуск при входе в систему.

### Edge Cases

- Хранилище data protection выключено: приложение показывает подсказку `secret migrate`.
- Helper не запускается: приложение показывает ошибку и кнопку «Продлить».
- Touch ID отменён: приложение показывает «Отменено», буфер обмена не меняется.

## Requirements *(mandatory)*

<!-- утр-100: 1.9 — идентификаторы заданы шаблоном spec-kit -->
- **FR-001**: Приложение вызывает только `bin/secret` и helper. Своих вызовов keychain нет.
- **FR-002**: Значение идёт в буфер обмена через `secret copy`. В память приложения значение не
  попадает. Новое значение идёт в `secret set` через stdin.
- **FR-003**: Подпись ad-hoc, hardened runtime, без entitlements.
- **FR-004**: Интерфейс на русском, клавиатура: ⌘F, стрелки, Enter.
- **FR-005**: `--selftest` проверяет разбор вывода команд без интерфейса.

## Success Criteria *(mandatory)*

<!-- утр-100: 1.9 — идентификаторы заданы шаблоном spec-kit -->
- **SC-001**: Тест: `--selftest` проходит. В бинарнике нет вызовов `SecItem*` и entitlements.
- **SC-002**: Ручная проверка: все действия из US1–US4 на рабочем хранилище.
